# YGO-Kito 分阶段开发与 100 小时训练计划

日期：2026-10-21。状态：建议草案，待逐项讨论及原型验证；不是启动开发、租用云资源、下载模型或训练的授权，也不修改现行 1.0 定稿。

已给定的规划边界：私密 GitHub 仓库承载资料与版本；代码编写挂载云端 Codex；训练阶段转腾讯云 Linux 单卡环境；整个训练阶段最多约 100 小时云算力，优先减少空转并尽早止损。具体机型、单价与采购尚未承诺。

## 目标与候选基线

保留标签驱动构筑、CB 推导、对局、复盘、自训练及本地使用的完整产品目标。首轮以有限卡组完成可复现闭环，不把这一验收范围替代最终产品目标，也不承诺全卡池强 AI、超人胜率或完整 Android 成品。

候选基线为 Python/PyTorch 的小型候选排序或策略价值网络，SQLite 管理卡片、标签与版本，训练轨迹分片存储。规则引擎给出合法候选，搜索与模型参与选择；LLM 不裁定合法性。LoRA 后置，当前计划不采用 DeepInfer。这些是本轮建议，并非用户已批准的全部技术选型。

## GPU 租用前的阶段

### A：规则与版本闭环（Codex/CPU，不租 GPU）

- 任务：固定同系兼容的 core、scripts、cards.cdb、禁限规则、协议和 bot 版本并记录哈希；打通 headless 完整对局、合法动作适配、玩家可见观察过滤及回放复现。先单轴再二轴，固定训练集、验证集与独立终验的卡组和代表性局面。
- 产物：兼容版本清单、规则与随机合法 bot 基线、代表性局面测试、可复现回放及观察字段说明。
- 进入：确认本阶段的兼容目标和代表性场景。退出：完整对局可复现，合法动作与信息边界检查通过，训练/验证/终验划分固定；失败不得进入训练。
- 决策点：具体引擎兼容分支、协议与 bot 组合；YGOMobile/YGOPro 客户端兼容是否首阶段必达仍待用户答复，不预设结论。

### B：数据与可迁移训练管线（Codex/CPU）

- 任务：实现数据采集、整局分割、训练/评测/恢复脚本、依赖锁、日志和云迁移包；CPU 验证前向、损失与导出。训练输入不含暗牌或未来抽牌。
- 产物：带版本的数据分片、明确的动作编码、一个小模型基准架构、可在 CPU 运行的验证记录、依赖锁与迁移包。
- 进入：阶段 A 通过。退出：CPU 验证与恢复流程通过、数据无泄漏，训练包可迁移后才租 GPU。CPU 可完成的准备、下载与清洗提前做；不假设 Codex 有无限免费 CPU。
- 决策点：动作编码与候选表示、小网络基准架构、数据分片格式和训练/推理接口。部署后端及客户端框架继续保留为待决事项。

## GPU 阶段与预算门槛

按单卡累计实例小时计：一台单卡实例运行 1 小时计 1 小时，多卡按卡数乘算。安装、下载、空转、失败、教师 GPU 推理和评测均计入，不按 GPU 利用率折扣。以下是上限，不是必须花满的目标。

| --- | ---: | --- | --- | --- | --- |
| C：准备与吞吐小试 | 6h | 部署已准备好的迁移包；测峰值显存、样本与对局吞吐、端到端时延，形成吞吐记录与训练步数预算 | A/B 已通过 | 按实测反推样本数和步数，性能或恢复链路不达要求则暂停修正，不承诺百万局或胜率 | 具体腾讯云机型、批量与并发等实测参数 |

| E：搜索教师与价值学习 | 24h | 利用搜索教师辅助或价值学习；合法观察下采样未知信息；输出轨迹、模型与消融评测 | D 已显示有效；教师成本可计量 | 同搜索预算和同墙钟预算均比较；无稳定增益则停止本分支 | 搜索预算、教师轨迹筛选和价值目标 |

模型/搜索比较须固定时间预算、对手与先后手设置，以完整对局隔离训练、验证和独立终验；策略只能看合法可见信息。

## 冻结评测与客户端决策

终验记录配对胜率及置信区间、目标终场达成率、非法响应、超时、P95/P99 端到端延迟和峰值显存。1–3 秒是端到端目标，不是性能保证。

部署后端在导出一致性与目标设备实测后锁定。客户端框架在核心接口稳定且 PC/Android 桥接完成最小验证后锁定，不在训练预算内追求完整客户端。首阶段是否必须兼容现有 YGOMobile/YGOPro 客户端仍是待答事项；未答复前不代替用户选择兼容目标。

## 预算、恢复与止损

- 完整 checkpoint 记录模型、优化器、调度器、RNG、步数/数据游标、组件与数据版本和累计预算；放在持久存储，并实际试验恢复。
- 训练前预定连续评测无改善的停止条件。无改善时停分支查数据，不无脑加时；退化可回滚到已验证版本。
- 保留终验 10h 与故障 18h。阶段预算挪用须明确记录并确认；未用的 LoRA 额度可以不花。
- 设置实例外的计费告警和到预算停止机制。训练进程退出不代表停止计费，须确认云实例停机状态；实际金额仍取决于实际机型与小时价。

首轮 100h 的可交付目标是：可复现的有限卡组闭环、有效权重或更优规则基线、独立评测记录、恢复能力及本地加载接口。所有执行仍须遵守后续确认的阶段范围与选型。
