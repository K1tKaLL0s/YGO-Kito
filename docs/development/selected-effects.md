玩家 0 通过真实合法动作盖放两张卡并结束回合。玩家 1 在下回合发动双龙卷，经过费用丢弃、单个放置、最多两个对象选择等多个真实窗口。

- `negate`：玩家 0 用上回合盖放的干扰阵响应，并丢弃 1 张作为费用。真实连锁 2 否定连锁 1；两个费用都不退回，双龙卷被效果破坏，未发动的旋风继续盖放。
- `resolve`：玩家 0 不连锁，双龙卷实际处理破坏两个已选盖放目标。只支付双龙卷的费用，不支付干扰阵费用。

检查原生 `REASON_COST|REASON_DISCARD`（0x4080）、`REASON_EFFECT|REASON_DESTROY`（0x41），以及支付费用在链处理前发生；没有把丢弃成本算成处理效果。还检查无目标时旋风没有发动候选、当回合盖放的干扰阵不能发动。完成条件是链结束后实际场面/墓地一致，随后释放本地对局；不宣称赢局、联机投降或通用效果支持。

原生集成用例会故意绕过外层保护向真实核心发送“丢弃 0 张”，确认核心返回 `MSG_RETRY`；外层 API 则会先拒绝不存在的费用选择。这个故障注入只证明拒绝路径，不计作成功执行卡效的替代品。未知消息、超范围选择继续 fail closed。
