## 目标与现状

目标是全本地卡池的通用短标签词典，复用现有效果／cost 语义，积木与连接件分开，并供当前构筑接口实际读取。`construction_effect_blocks.reviewed_effect_blocks` 目前只有卡组送墓、墓地融合两类默认标签；`effect_records` 已保留费用、处理、次数、来源和未知项。`construction_inventory` 已修复未知配套不能算覆盖、字段归属不能按卡名子串判断。本次承接这些接口，不恢复旧评分和私有账本。

不涉及模型分工迭代的后续实施、训练更新、CB 提议／推理、原生引擎、对局、权重迁移或手工改牌表。原 18 维机制输入和 checkpoint 布局保持不变。

## 数据与不变量

`CDB → MechanismCatalog → effect_records（追加 block_view）→ 卡片词典视图 → SQLite／当前构筑适配器`。标签只有 `dimension + value`，区域、数量、random、来源、分支、次数和限制均独立。每个效果的多个动作仍共享效果身份；选项使用 one_of 分组；同编号的 P／怪兽效果有不同作用域。cost 的资源变化为 activation_payment，效果处理为 resolution 或 continuous，召唤素材另列。

新增视图有自己的版本，不覆盖旧 `public-effect-clauses-v2` 的固定特征含义。新语义句式以文本和结构分类，不按卡号或主题硬编码。完整原文只保留在来源记录，不能塞入短标签。未知表示尚未识别，不等于不存在，也不算构筑配套满足。

## 风险与回滚

主要风险是中文否定／引用／触发前提被误识别为功能、旧卡文的发动边界不明确、选项和分区串用。验证覆盖这些正反例；无法识别的部分保留原文及未知状态。字典只读取本地现有卡文，不运行裁定引擎。本次版本的回滚限于上述新增视图和建库产物；当前工作区已有的统一构筑、召回和学习接线修改保留。生成失败保留旧正式词典，使用同目录临时文件完成后替换。没有待答问题。
