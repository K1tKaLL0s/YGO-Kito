三条约定：

1. 判断是让评分方向对齐人的评价，不是让参考赢；与实现方向相反时改细则，不改牌表。
2. 少数几对不足以同时确定“目标值、权重、饱和曲线”，它们只用于约束取舍；能用事实与已确认要求决定的题先由实现处理，不占用你的判断。

## 判断对

### P1 用 0.9 入口换一张融合组件（整体取舍，不单独定权重）

- 改动：候选形 1 张**反响** → 1 张**小美人鱼**，其余不动。
- 代价：自己回合入口候选 3→2 张，有效 9.4 → **8.5**（−0.9）。
- 收益：送墓融合组件 4→5 张，有效 3.8 → **4.8**（**+1.0**，首张按 1.0）；并多一个响应窗口的随机堆墓 3。
- 问题：这副**明显更好／略好／差不多／略差／明显更差**？
- 同时要记录：这次交换涉及入口供给、送墓融合来源、响应型堆墓与相关素材关系四类变化，因此只能判断整体取舍，不能据此单独推出“融合权重是入口的几倍”。
- 敲定：Q1（目标值该不该声明、声明在什么量级）、Q4（认同不认同饱和）。

### P2 用同样的 0.9 入口换一张定向送墓（与 P1 对照）

- 改动：候选形 1 张**反响** → 1 张**爪音**，其余不动。
- 代价：入口 9.4 → 8.5（−0.9）。
- 收益：爪音 2→3 张，卡组定向送墓 4.7 → **5.6**（+0.9）；场上/对象前提保留。
- 问题：与 P1 相比，**更好、差不多，还是更差**？
- 敲定：Q2（两类功能相对价值）。两题合计仍不足以同时定 target／weight／curve，只用来约束取舍方向。

### P3 第三个同名副本换成针对性额外工具（敲定 Q7、Q6）

- 改动：候选额外区水仙、鲁莎卡、卡雷多哈特各留 2 张，空出 3 位放 3 张针对性工具。
- 需要写明才能判断：三张工具分别针对什么问题、各自需要什么素材与召唤条件；被去掉的第三张原本覆盖什么用途（续航、备用、还是只是同名多一张）。
- 问题：①整体**更好／差不多／更差**？②去掉的第三张原本有无明确用途（有／没有／不确定）？
- 注意：“有备用用途”本身不足以证明值得占位；要看它是否解决了别的卡没解决的问题。

### P4 名称与分组（拆成两题，检查题）

- **P4a 纯重命名**：参考形 3 张**塞壬**换成 3 张“效果相同、卡名不同”的假想卡，但保留全部名称引用、同名使用次数分组与限制关系。
  - 问题：评分**必须保持不变**，还是应当变化？
- **P4b 改变同名分组**：把 3 张同名换成 3 个不同名（即使效果相同）。
  - 问题：这属于规则含义变化（同名次数限制不再共享），评分是否应当变化？
- 敲定：C5（无卡名配方）的边界——纯重命名必须不变；改变名称分组则允许变化，但需说明变化来自规则关系而非卡名本身。

### P5 一张关键件的取得条件未核实（证据题，不参与权重拟合）

- 改动：候选形把**哀唱**的取得条件标为“未核实”，其余不动。
- 需要先回答：它承担的哪个用途？这个用途是否为当前阶段所必需？
- 问题（按你的回答选一种处理）：

| 情形 | 建议处理 |
|---|---|
| 承担必需用途且未核实 | 该用途尚未满足，不得通关；先查证或改用已核实来源 |
| 承担非必需用途 | 记录为未核实，不抹掉已确定的改进 |
| 与当前阶段无关 | 记为 deferred，不参与本阶段分母 |

- 敲定：Q9（未知在优化反馈中的优先级）、Q10（阶段划分）。

### P6 加一张争用通召机会的强卡（先说清替换对象）

- 改动：参考形加 1 张需要通常召唤的强卡。必须同时说明：替换掉哪一张（保持 40 张），或明确接受 41 张带来的其他变化。
- 问题：①更好／差不多／更差？②这张卡与主轴是**互为备选**（任选其一即可）还是**共同必需**（同一目标要两者同时用）？
- 说明：两张都需要通召，不足以直接判定整副有缺陷；只有同一必要用途要求同时使用时才需要进一步判断资源如何满足。
- 敲定：Q6（限制相容如何记分，以及备选/共同必需的区别）。

### P7 同为 40 张、同等必要功能下的占位比较（重写）

- 改动：保留 P1 修正后的事实——参考形主轴占 18 位、候选形占 21 位，两者都已满足同量入口。

- 问题：①A 空出的三位若填了具体用途，这副更好／差不多／更差？②若尚未填入，是否只按“剩余构筑空间”记录、不据此认定更强？
- 敲定：Q8（占位效率是否进标量、用什么基准），并避免把“牌数变少”当成占位更优。
