## 本次发现并修复的问题

真实候选池中的“娱乐伙伴 异色眼祭司”在灵摆效果、怪兽效果两段中都出现①。原关系索引只用卡 ID 和效果编号，造成 `catalog/explicit relation ID collision`，第一次真实构筑在第一阶段中止。

修复限定在 `construction_relations._record_facts`：同一卡存在重复效果编号时，用文本片段顺序区分关系、输入端口及“这个效果”次数池，并加入 `repeated_effect_number_scope_unresolved`；普通唯一编号保持原标识，共享次数限制及真实显式 ID 冲突检查保持原行为。未修改卡池、候选生成、卡效解析器、模型特征或权重。

新增回归覆盖重复①下不同支付量、不同输出量、独立端口和次数池，以及未知范围不得变为已支持。三组明确测试 `tests.test_construction_layer_flow`、`tests.test_construction_relations`、`tests.test_construction_layers` 合计 93 项通过，0 失败/错误/跳过，2.093 秒。随后以上完整真实运行成功结束。

运行记录脚本还曾误读 `budget` 而非 `candidate_budget`，在正式构筑前中止；该临时脚本错误已修复。独立评分的新 WSL 进程需要重建 `/tmp` 资源缓存，已使用既有本地归档和正常恢复函数完成，没有下载或安装依赖。
