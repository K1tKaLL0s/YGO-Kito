# 全卡库与效果积木核对

后续逐卡明细与更新后的问题清单见[逐卡核对续报](2026-11-11-card-library-semantic-review.md)。补查确认：旧 `alias=0` 范围漏掉 19 张有独立卡文的规则同名卡，项目独立非衍生物卡应为 14,299 张；下文 14,280 是旧筛法实际选中的范围。最终确认问题与待复核项以续报为准，不能将本页早期候选全部计为已确认错误。

已完成百鸽本地整库与项目卡库的逐条数据比对，以及当前效果积木的全库扫描。原始卡片数值大体一致，但存盘词典没有同步到当前程序，现有效果积木还有明确的误判、漏记和导出故障，不能据此判为正确全面。全部卡效的逐项语义复核仍未完成。

本次只新增核对脚本、下载资料和报告，未修改运行源码、绑定卡库、正式词典或权重。此前 R0—R11 的定向测试记录保留，本报告补充它们未覆盖的全库问题。

用户补充要求直接使用本地百鸽数据后，没有继续逐卡查网页。项目内未找到已有的百鸽整库，随后从百鸽公布的[整库接口说明](https://ygocdb.com/api)下载一次压缩包及校验值，再离线核对。此前仅查看过六个代表案例的单卡页及其官方链接；这些访问没有计入全库覆盖数。

31 张文本差异中，13 张是 CDB 附加的“暂时无法正常使用”程序注记；其余 18 张是卡文异文。需要优先核定「光之灵堂」的“原本等级／等级”，以及「三色零件」是否明确包含检索「光之黄金柜」本身。完整新旧文字在逐卡差异文件中，尚未将这些异文裁定为同一种错误。

「希望皇 拟声乌托邦」「拟声蜥蜴」「无垢大艺术-『黄昏之变幻』」三个超大 `setcode` 值存在疑似浮点精度损失：两端整数不同，但转成双精度浮点数后相同。原始整数差异完整保留，没有通过舍入消掉。其他字段代码差异包括鹰身女郎相关细分字段和魔之龙札两卡，需要按实际字段归属核定。

反向也检查了全部本地记录。两张独立卡「德科平」「伟大的战士 泰勒」未在百鸽整库中匹配到密码；另有 572 条别图／别名、200 条非别名衍生物不在百鸽快照中。82 条百鸽新增资料保存在 staging，本次没有改动运行卡池或发行允许清单。百鸽整库未提供 CDB 的 `alias`、`category` 和 `str1…str16`，这些字段只完成了项目两份 CDB 之间的一致性检查。

当前全库实际出现 128 类功能积木。已为每类保存一张代表卡及对应原文，用于检查分类粒度；这部分是分类代表例，未冒充该类全部卡效的语义验收。当前还有三个完全未分类分组：被诅咒的无花果、警车机人、巡逻机器人，分别涉及发动限制或检视盖卡。19,836 个分组仍带某些细节未知；该数是定位资料，不是错误率或漏效张数。
