## 实际代码结果

| 位置/关键符号 | 本批结果 |
|---|---|
| `multifactor/contracts.py`：GraphNode、GraphEdge、AnalysisGraph、StructureLink、FunctionSeed | 独立 v3 图契约；受控数值特征与关联/证据字段分开；三分区整数数量及 known/empty；完整图和全局索引稀疏边的数值分块导出 |
| `multifactor/semantics.py`：build_analysis_graph、GraphBuild、GraphBudget | 运行时共用事实构造，接收 v3 输入、卡表/效果快照、声明关系和组合契约；不反向导入训练目录；复用既有 analyze_card、selector/matches/requirement、material_matches |
| `multifactor/axis_candidates.py`：generate_axis_candidates、CandidateSet.batches | 自然候选生成、必要依赖闭包、普通关系两轮扩展、重叠成员、条件/模式约束、明确供需父子候选、32 项分块查询及预算状态 |
| `training/axis_generic/features_graph.py`：Features.make_graph_v3/graph | 通过显式 `feature_schema=axis-graph-v3` 委托共用构造器；旧配置和原 `_legacy_graph` 路径保留；旧 variant 名称不能代替实际观察变化 |
| 同上：training_candidate_view | 训练阶段可增加正例查询支持；函数、条件、模式及置信度必须来自现有观察查询；注入标记只在 provenance；自然候选结果和召回口径保持独立 |
| `multifactor/__init__.py` | 导出图与候选 API；本批未修改网络、训练器、评分器或 M1–M2 求解核心 |

新图包含 card、effect、mode、function、axis、dependency、condition、section、resource 节点。复制数量保留实际整数，Main/Extra/Side 分别汇总；未知区域、空区域和 padding 使用不同标记。公共资源别名连接同一容量池，不把重复描述变成额外库存。资源条件保留 owner、时段、区域、消耗方式及已知状态。

效果按条款和可明确归属的印刷模式建立功能节点。检索/调用目标仅使用完整识别的选择器及已知数量；未解析选择器、未知数量和未知模式归属保留未决记录。一次调用的替代目标以独立选择约束表达，避免把多个目标拼成同一最小包。材料关系复用现有材料匹配器，保留完整分配尚未确认的条件；没有把候选召回当作召唤合法性。

必要指名关系继续闭合至完成或循环去重，普通候选扩展默认两轮、每轮每种子八分支。独立单卡保留为 unit；共享桥接成员不会自动合成一个轴。更大候选只在有明确连接独占成员的供需关系时组合，并保留较小候选的关联。

候选排序使用事实可信度、受控功能覆盖和匿名结构特征。软分支边界并列时保留整组，不按卡号择取前缀；硬全局数量边界则整组留出并标记预算不足。检查预算耗尽时撤下未完成的候选扩展轮。自动目标匹配预算不足时撤下整个未完成自动匹配集合，完整卡片、效果和声明依赖图继续保留。组合闭包未完成时不使用其截取分支作为自然候选。

默认图预算为 16384 节点、131072 边、32768 次自动关系匹配检查；默认数值分块为 128 节点、2048 边。图实体预算不足时明确拒绝返回截断图。候选预算为两轮、每种子八分支、65536 次检查、4096 个候选；单次 32 项仅是查询分块大小。
