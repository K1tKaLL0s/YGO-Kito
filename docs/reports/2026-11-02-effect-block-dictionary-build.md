## 存储粒度

| 层 | 数据 | 例子 |
|---|---|---|
| 身份 | `identity_tags`，维度和值分开 | 机械族、暗属性、3阶、超量；阶级不写成等级 |
| 效果功能 | `blocks` | 检索、特召、送墓、控制权取得、补充超量素材 |
| 费用 | `cost_blocks`；发动费用为 `activation_payment`，攻击费用为 `attack_payment` | 光之援军：发动 cost 卡组顶 3 张送墓；卡通怪兽攻击支付 LP |
| 召唤手续 | `procedure_blocks`，`summon_procedure` | 无连锁特殊召唤、上级召唤解放数量与手续中的移动 |
| 限制 | `restrictions`，独立 restriction 索引 | 额外特召限制、攻击限制、取对象保护 |
| 说明 | `description_blocks`，独立说明索引 | 非效果仪式怪兽关联、召唤素材说明、空灵摆栏 |
| 连接件 | `connectors`，独立索引 | ns、ss、被效果送墓、自己主要阶段、持续适用 |
| 限定与来源 | 区域、数量、random、目标引用、次数、分支、次序、原文位置 | 爆风偏向：双方各 2 张、效果处理；命中后的分支不展开 |

功能标签没有塞入整段卡文；完整文字保留在 `source_records`。每个动作仍属于原效果分组。P 区和怪兽区重复的①分开；同一区域重复编号仍保留分区未知。旧式无编号卡文标记为 `unresolved_text_group`，不会宣称其全部句子已经分成精确的独立效果。

无脸幻想师的两选项共用一次费用，选项 A 与选项 B 分开；B 的回收和可选特召保留处理顺序。现有关系适配器接收 `choice` 和前序动作条件，避免将两选项并作一次发动的全部收益。召唤素材条件独立于发动费用。

## 与既有修复的衔接

复用 `EffectSemantics` 的来源、触发、费用、次数和限制，经 `effect_records` 扩展为 v2；同一积木识别结果回写其 `operations`，因此新词典修正不会被旧操作字段绕过。具体回归包括：

- 光之援军的 cost 送墓与爆风偏向的效果送墓分离；随机／定向独立于 cost／effect。
- 灰流丽列举的被响应能力、增殖的 G 等待的特殊召唤事件，不变成它们自身提供的功能。
- 伊索德处理中的“送去墓地的卡”是已付费用的引用，不产生第二次效果送墓。
- 融合召唤过的怪兽、卡名“融合”、被战破送墓等描述，不冒充融合召唤或效果送墓功能。
- 同一效果的多笔费用保留各自区域；手牌／场上的任选费用不压成单一区域。
- 取对象、cost、效果自毁、召唤素材、持续适用和分支选择分别保留。
- 配套检查继续使用已修复的字段代码与严格选择条件；未知依赖不算确定覆盖，可选动作的配套也不会从整卡检查中消失。零预算和未知标签的禁读回归保持通过。

版本为 `public-effect-blocks-v1`、`public-effect-records-v2` 和 `public-mechanism-summary-v2`。原 18 维机制输入及模型参数布局保持原含义，权重没有迁移或更新。结构化接口新增可用信息，与神经模型的训练学习是不同状态；本次只完成前者。
