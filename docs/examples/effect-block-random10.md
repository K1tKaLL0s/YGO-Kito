# 全卡池随机10张卡：效果积木确认样例

2026-11-02。用户已确认基础 CB 可包含固定随机堆墓动作，不推理命中分支，并要求明确区分 cost 与效果。本批分类和粒度现已获用户确认，并已据此实施全卡池词典 v1；实现和覆盖结果见[建库报告](../reports/2026-11-02-effect-block-dictionary-build.md)。训练与 CB 执行继续暂停。

样本从项目本地 CDB 的14280个独立非衍生物条目中随机无放回抽取，排除别图别名条目，不按禁限、发行时期、字段、卡种或难度筛选。一次抽样，没有换卡；本次恰好均为怪兽，包含超量和灵摆。抽样种子为13116958636307431405，原卡文和抽样记录保存在[样本文件](../reports/2026-11-02-effect-block-random10-sample.json)。以下是根据卡文整理的拟入库案例，不是现有自动解析器的输出。

## 1. 已有语义如何复用

[效果语义接口](../development/effect-mechanism-construction.md)和 `effect_records` 已将发动费用记录为 `costs`，效果处理为 `operations`，资源变化分别带 `activation_payment` 与 `resolution`。已有[真实费用与连锁记录](../development/selected-effects.md)分辨 `REASON_COST` 与 `REASON_EFFECT`，并记录费用先于连锁处理发生。这里沿用这些区别，不恢复旧参考计分或 cost 折扣政策。

| 卡片 | cost 积木 | 效果积木 | 连接差别 |
|---|---|---|---|
| 光之援军 | 随机送墓：自己卡组顶3张 | 检索：卡组→手牌，4星以下光道怪兽1只 | cost 送墓不能接珠泪“被效果送墓”诱发 |
| 闪刀术式－爆风偏向 | 无 | 随机送墓：双方卡组顶各2张；条件满足后可将对方额外怪兽区怪兽回卡组 | 效果送墓可提供“被效果送墓”的事件来源；命中分支不在基础 CB 展开 |

两者都有墓地供给，但语义不同；cost 的用途仍可保留，不能为了避免误触发把它从词典中删掉。光之援军另需合法的光道检索对象；爆风偏向要求自己主要怪兽区无怪兽，回卡组部分在送墓后检查自己墓地魔法数量。依据：[光之援军官方说明](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=7868&ope=4)、[爆风偏向卡文](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=13948&ope=2&request_locale=ja)。

功能标签记录“做什么”；身份、费用、限制及短连接分别记录。召唤素材条件不等于发动费用；效果中的自毁、回收或特召也不能被挪入 cost。每个案例按具体效果保持关联，粗标签不独立发放额外次数。

## 2. 十张随机卡的积木

### 1. No.34 电算机兽 太字节（32003338）

身份：No.字段、暗属性、机械族、3阶、超量／效果怪兽。召唤素材为3星怪兽3只。

效果积木：控制权取得。cost：取除自身1个超量素材。连接：自己主要阶段起动。短限定：对方场上4星以下攻击表示怪兽1只、取对象、直到结束阶段；此卡效果每回合1次。3阶是自身阶级，3星×3是素材条件，不能混为同一等级标签。[官方卡文与费用说明](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=9658&ope=4)。

### 2. 无限起动 攀岩锚挖掘机（62034800）

身份：无限起动字段、地属性、机械族、4星、效果怪兽。

①积木：特召。cost：无。连接：ns／ss成功后。短限定：手牌→场上守备表示；机械族且地属性1只，排除同名。②积木：等级变更。cost：无。连接：自己主要阶段起动。短限定：取自己另一只机械族为对象，两只的等级都变为两者原本等级之和，持续至回合结束。①②同名每回合各使用1次。取对象单列，不当作费用。[官方说明](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=14392&ope=4&request_locale=ja)。

### 3. 古代的机械巨人－究极重击（95735217）

身份：古代的机械字段、地属性、机械族、8星、效果怪兽；卡片限制：不能特殊召唤。

①积木：贯穿战斗伤害。连接：攻击守备表示怪兽，持续适用。②积木：追加攻击。cost：丢弃手牌机械族怪兽1只。连接：自身攻击战破怪兽后；每回合最多2次。③积木：检索＋墓地回收。cost：无。连接：场上的自身被战斗／效果破坏后；卡组取指定卡名“融合”，同时回收墓地另一只古代的机械怪兽。③提供的是取卡功能，自身不因此获得融合召唤效果。[官方卡文](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=12997&ope=2&request_locale=ja)。

### 4. 云魔物－毒云（83982270）

身份：云魔物字段、水属性、恶魔族、3星、效果怪兽。

积木：破坏＋效果伤害。cost：无。连接：表侧在场的自身被战斗破坏并送墓。短限定：破坏击败自身的怪兽，并造成800效果伤害。自身战破送墓是触发前提，不是它主动支付的费用或提供的效果送墓功能。[官方卡文](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=7268&ope=2&request_locale=ja)。

### 5. 超量谍报士（72502414）

身份：超量字段、光属性、魔法师族、2星、效果怪兽；本身不是超量怪兽。

积木：补充超量素材。cost：无。连接：自己主要阶段，墓地起动。短限定：取自己场上希望皇霍普超量怪兽为对象，将墓地自身叠为其素材；同名每场决斗仅使用1次。这个区域变化是成为素材，不是复活或超量召唤。[官方说明](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=10608&ope=4&request_locale=ja)。

### 6. 雾动机龙·甲龙（32134638）

身份：雾动机龙字段、水属性、机械族、4星、灵摆／效果怪兽，灵摆刻度6。

P区积木：效果无效＋自身破坏。cost：无，自毁属于效果。作用条件：其他己方本家卡成为发动效果的对象；在P区存在期间可适用1次，不入连锁。怪兽区积木：除外。cost：无。作用条件：在怪兽区持续适用，将己方本家怪兽战破的怪兽除外。两区的①必须分开，不因编号相同合并。[官方说明](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=12425&ope=4&request_locale=ja)。

### 7. 暗眼幻想师·无脸幻想师（34314989）

身份：暗属性、幻想魔族、4星、效果怪兽；本地字段记录为空。

①共同 cost：丢弃手牌自身；连接为自己主要阶段、手牌起动。选择A积木：表侧放置，手牌／卡组的指定卡“看透心灵之眼”→己方场上。选择B积木：墓地回收→可选特召，取回除自身外、卡文记述“卡通世界”的怪兽，然后可从手牌无视召唤条件特召刚取回的那只。两项每次二选一，同名每项每回合各可选1次。②积木：战斗破坏保护；自身与怪兽战斗时，对交战双方适用。表侧放置不是检索；卡文记述关系也不等于自身取得卡通字段。[官方卡文](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=23159&ope=2&request_locale=ja)。

### 8. 急袭猛禽－穿刺伯劳（60950180）

身份：急袭猛禽字段、暗属性、鸟兽族、4星、效果怪兽。

①积木：表示形式变更。cost：无。连接：在自身ns／ss成功的当回合，于自己主要阶段起动；取场上表侧攻击表示怪兽为对象，改为表侧守备表示；每回合1次。②积木：墓地特召。cost：无。连接：自身攻击过的回合，自己主要阶段2；取墓地本家怪兽1只为对象并复活；同名每回合使用1次。①是当回合可起动，不是召唤成功时立即发动的诱发效果。[官方卡文](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=11691&ope=2&request_locale=en)。

### 9. 命运英雄 恶魔人（41613948）

身份：命运英雄／英雄字段、暗属性、战士族、3星、效果怪兽。

积木：暂时除外。cost：无。连接：自己主要阶段起动。短限定：取对方怪兽1只为对象，至发动后的第2次自己准备阶段；发动与处理时自身均需表侧攻击表示；此卡效果每回合1次。玩家限制：发动该同名卡效果的整个回合不能攻击宣言。不能攻击是整回合限制，不是费用，也不是仅该怪兽不能攻击。[官方卡文](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=6658&ope=2&request_locale=ja)。

### 10. 遗式虚巫 瓦尼蒂（93506862）

身份：遗式字段、水属性、水族、2星、效果怪兽。

积木：响应限制。cost：从手牌丢弃自身。连接：自己主要阶段，手牌起动。短限定：本回合，对方不能连锁遗式仪式魔法的发动，也不能在遗式仪式怪兽仪式召唤成功时发动卡或效果；并非整回合禁止一切发动。它保护仪式相关窗口，不执行仪式召唤或无效已经发动的效果。[官方说明](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=9159&ope=4&request_locale=ja)。
