## 2. 主干CB实际完成什么

初始条件为手牌雷诺、通召可用，卡组中有梅洛和红人鱼，额外有水仙；相关效果未用，所列处理成功。先单独核对主干，再在各诱发窗口接入随机命中带来的分支。

| 顺序 | 动作及处理 | 资源和次数变化 |
|---|---|---|
| 1 | 通召雷诺73956664，①从卡组送梅洛74078255 | 消耗通召与雷诺①；第1次定向送墓 |
| 2 | 梅洛②，以自身和场上雷诺融合水仙92731385 | 两份素材回主卡组；梅洛的同名融合效果已使用 |
| 3 | 水仙①选择红人鱼4928565，送墓 | 第2次定向送墓；水仙①已使用 |
| 4 | 红人鱼③从自己卡组顶送2张 | 第1批随机送墓；红人鱼③已使用；处理相应诱发窗口 |
| 5 | 水仙②取自身为对象，从墓地特召红人鱼，并把水仙送墓 | 红人鱼在场、水仙在墓地；水仙②已使用 |
| 6 | 同一诱发窗口组成C1水仙③、C2红人鱼② | 逆序处理：红人鱼先送自己卡组顶3张，水仙再送5张 |
| 7 | 连锁处理结束 | 处理新一批墓地诱发；进入按命中内容展开的后续分支 |

主干合计定向送墓2次、每次1张；随机送墓3批，数量为2＋3＋5＝10。作为“只执行所列主干”的状态投影，场上是红人鱼，水仙已在墓地；三种本家送墓融合效果中仅梅洛已用，塞壬和小美人鱼仍可用。

定向2张、随机10张表示送墓处理量，不是12份独立净收益。梅洛、雷诺已经返回主卡组，之后可能再被送墓；红人鱼从墓地回场，水仙又成为墓地素材。构筑判断应继续使用实际区域、实体和次数。

水仙②的特召与送墓在规则上视为同时处理，因此红人鱼②和水仙③进入同一诱发窗口。水仙②自身是起动效果，要在前一连锁及相应诱发处理完成后进入可发动时点。红人鱼③的先堆2与后面的堆3＋堆5属于不同窗口，前2张的命中可能先带来检索、追加堆墓或融合选择。[水仙官方说明](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=17444&ope=4&request_locale=ja)、[红人鱼官方说明](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=18153&ope=4&request_locale=ja)。

若先堆2已经触发分支，继续保留这条10张主干时，要检查分支是否占用了水仙、墓地红人鱼或后续所需次数。后面同一连锁中的堆3与堆5之间不插入新连锁，新增诱发在该连锁结束后的窗口处理。

## 3. 这条CB需要哪些卡支撑

这条具体起手线的最小卡种依赖是主卡雷诺、梅洛、红人鱼，加额外水仙。主干用水仙②复活红人鱼，没有使用红人鱼①，因此不需要为这次复活额外准备其手牌自跳所需的除外资源。

| 支撑关系 | 新参考中的投入 | 实际作用 |
|---|---|---|
| 雷诺进入场上 | 雷诺3；珍珠世界1可检索雷诺 | 提供通常召唤后定向送墓入口 |
| 首次融合 | 梅洛2、水仙2 | 梅洛与雷诺满足水仙素材；两张梅洛增加取得/留库余量，同名融合次数仍只有一次 |
| 水仙后的供给 | 红人鱼3 | 水仙①可以送它，②可以从墓地复活它，同一份实体先后兑现③堆2与②堆3 |
| 替代的水仙入口 | 简易融合1 | 可以直接形成水仙，再接红人鱼部分；此分支未先使用梅洛融合，起点代价及剩余次数与雷诺线不同 |
| 红人鱼的其他获取途径 | 芬里尔狼3、天魔世界1；舞台旋转连接两种场地 | 支持取得红人鱼及其他起点的展开，按实际区域和已用效果接入，不统一当成雷诺单卡10张线 |

红人鱼作为本家目标可以被水仙取用，同时具有俱舍字段，因此能接入芬里尔狼、天魔世界的获取路径。字段共享在这里有实际接续作用。

芬里尔狼的空场特召要安排在雷诺通召前；取到红人鱼后，若使用其①从手牌特召，还需手牌/墓地可被除外的本家或俱舍卡。已经使用过红人鱼②的分支，后来复活同名卡也不会再得到一次②堆3。这些差异决定不同入口的真实产量与资源余量。

四张堆5组件对应凯尔柏克、阿基多两种同名限次效果；在这两种基础效果范围内，分别兑现一次为追加5＋5，不是四张各堆5。追加量要随实际命中、次数和是否发动计算。双方堆墓对对方的供给也属于该选择的结果。

白雪使用的是实际可支付的资源。融合已经把部分卡送回卡组、回收效果已移走某些牌，都会改变可支付库存；采用米德拉什终场时，白雪特召也受其持续限制影响。

当前额外中的其他卡按对应路线检查。阿莱斯哈特通常素材为3只7星，特殊叠放方式需要香格里拉茧发动效果的前提，且自身会把送墓改为除外；它属于需要单独说明进入条件与顺序的备选终端。鲜花可以关注红人鱼7星与灰流丽3星调整的组合，但本雷诺线已经占用通召，灰流丽如何到场仍是实际依赖。不能仅由属性/等级匹配就把这些终端算成主干固定收益。

## 5. 理想命中的一条具体延伸

用户描述的“鲁莎卡＋另一融合，雷诺回场，手牌塞壬＋本家魔陷”可以通过同一套资源落实。下面给出一个成立条件明确的组合例子，说明用途之间如何配合；它不是对发生概率的测量。

初始手牌除雷诺外，另有一张可供雷诺②送墓的本家牌，例如另一张红人鱼。其余关键卡在需要时仍处于所列区域：

1. 红人鱼③的先堆2命中哀唱、弦声。相应墓地效果分别从卡组取得一张塞壬和一张爪音。由于哀唱已在墓地，弦声本次取的是卡组中仍存在的爪音。
2. 水仙②及后续堆3＋堆5成功，其中命中另一张塞壬、小美人鱼、影依兽、雷诺。手牌塞壬与被堆到的塞壬是两份实体。
3. 雷诺②从墓地特召自身，并把初始保留的另一张本家手牌送墓；该雷诺带离场除外限制。手里的塞壬和爪音可以保留。
4. 墓地塞壬用自身＋墓地水仙融合鲁莎卡；小美人鱼用自身＋影依兽融合米德拉什。两次融合使用不同卡名的效果与不同素材，不争用同一个水仙。
5. 在相关诱发组链与处理安排中，先完成需要的复活和融合，再让米德拉什成立；例如其融合处理安排在这些特召之后。影依兽的送墓抽卡可以在该窗口利用，随后回卡组不会再触发一次抽卡。

于是该分支可以形成场上红人鱼、雷诺、鲁莎卡、米德拉什，并保留手牌塞壬与爪音。若同批还命中凯尔柏克或阿基多，可追加堆墓；若再取得白雪及可支付资源，则继续按窗口和限制接入白雪用途。

这说明用户给出的丰富后续场面有明确的资源路径。评价其发生频率时，应联合考虑起手、各批命中、检索、追加供给、素材分配和次数，不能把各项单独的命中概率相加，也不能把抽样命中自动等同于完整终场。当前分析已说明接续机制，未用固定牌序冒充随机环境成功率。

## 6. 对关系闭环设计的直接补充

以下信息已归纳到[第二层设计](../current/construction-scoring.md)。本例是用户提供并已分析的CB依据，第二层从中提取构筑关系；自动求出主干、处理连锁及展开随机后续仍属于CB工作。本例的牌表及CB事实保持原范围。

可提取的构筑信息包括：

- 供给与接收用途：红人鱼的随机送墓可支持符合来源及原因条件的融合、追加供给和墓地用途；接收组件的配置也影响供给能被怎样利用。
- 材料支撑：鲁莎卡需要水仙及相应融合组件，影依兽＋米德拉什需要影依材料、暗属性融合组件与额外位；不能只看宽泛的堆墓标签。
- 次数与库存：多一张同名卡不等于多一次融合或地天使效果；红人鱼的不同效果分别受各自限次约束。
- 共同资源：融合材料、回收与白雪支付可能争用同一库存；需要记录用途竞争，不能将所有潜在产出合成一个已实现终场。
- 限制条件：米德拉什与其他特召存在顺序依赖；第二层保留该依赖，具体安排由CB判断。

主干中场上红人鱼、墓地水仙、两种未用融合效果及随机送墓10张，是这条已知CB在其条件下的结果。第二层可引用这些依据比较支撑与接收组件，不将其推广为任意珠泪配置的固定产出。事件批次、触发窗口和实体分配保留在本CB说明中供后续使用，不要求构筑层另建状态机。

原r1直接“水仙送第二种融合组件→鲁莎卡”的例子继续保留。第二层比较的是两类关系支持什么用途、需要什么组件、存在哪些竞争及占位差异，不在每次构筑编辑时求解水仙应当选谁，或计算多阶段随机终场概率。Q仅保留已有局部诊断，不成为调用CB的前置任务。
