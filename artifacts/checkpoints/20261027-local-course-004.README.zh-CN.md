# 已闭合的16场课程保存点

该包保存16场完整正式BO1后的同绑定主课程状态，包含完整四角色参数、优化器/RNG/反馈消费、匹配的DataIndex、原始构筑证明和准确的Python执行版本。manifest记录课程指针、逻辑索引摘要、完整文件清单及真实更新游标。主课程在独立索引的冻结候选比较期间保持不变；备份前后核对同一指针，并核对备份索引与checkpoint逻辑摘要。当前健康训练没有为归档停止。

它是闭合回退点。正在进行的第二轮候选比较不在此包中，继续保存在原本机目录，不能用此包覆盖当前训练。优化器没有由未完成比较获得标签。正式训练最低600 BO1+400 BO3、独立验收及胜率目标不变；16场不表示达标。

在新的独立目录依次恢复原云端002、本机foundation003及此course004，并保持原文件/哈希；使用仓库的scripts/unpack_local_snapshot.py核验与安全解包。当前课程必须消费包内frozen-execution-source-003及execution-scripts，不直接把新PR通用图语义替换进去。原同路径本机WSL环境可按local-training.ps1的同身份Resume接续；其他位置、运行依赖或源码变化需要显式迁移，不改旧绑定冒充原地恢复。

第三方CDB、Lua、原生core、WindBot与Mono运行二进制没有装入此包。它们仍在已配置的本机隔离环境，来源与摘要按锁文件、前驱资产和runtime-identities恢复；本包不是完整第三方运行环境。代码继续在草稿PR8，未合并main。
